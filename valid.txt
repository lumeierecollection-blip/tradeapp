# OpenCode Task: Regime-Conditioned Backtest

**Repo**: https://github.com/lumeierecollection-blip/tradeapp
**Goal**: Test if regime filtering rescues the 3 partial survivors.

## Rules
- Read first. Report findings. Do NOT change strategy logic.
- The regime classifier already exists in `signal_aggregator/backend/ml/regime.py`.

## TASK 1 — Add regime filter to engine

In `signal_aggregator/backend/backtest/engine.py`:
- Add `--regime-filter` flag (default off)
- When on: only open trades when `classify_regime(features).iloc[i] == 'trend'`
- Keep everything else identical

Verify no existing behaviour changes when flag is off:
```
python signal_aggregator/backend/backtest/engine.py --symbol GC=F --strategy ma_cross --timeframe 1d
python signal_aggregator/backend/backtest/engine.py --symbol GC=F --strategy ma_cross --timeframe 1d --regime-filter
```
Both must exit 0. Compare trade counts (with-filter should be lower).

## TASK 2 — Re-run validation with regime filter

For each of the 4 survivors, run 3 tests WITH regime filter:
- Walk-forward (8 windows)
- Holdout 2023-2026
- Holdout 2021-2022

Report table:

## TASK 3 — Update verdicts

For each symbol, apply rule:
- **confirmed**: all 3 tests pass (sharpe > 0.5) with regime filter
- **improved**: 1-2 tests went from fail to pass
- **unchanged**: same pass/fail pattern
- **worsened**: any test went from pass to fail
